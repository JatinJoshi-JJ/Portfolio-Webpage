# 🚀 Personal Portfolio Website

> **Web Development Internship — Day 2 Project**

A modern, responsive, and production-quality **Personal Portfolio Website** built with pure **HTML5 and CSS3**.
The project focuses on strong frontend fundamentals, semantic structure, responsive design, accessibility, SEO, CSS-only interactions, and a polished professional UI.

The goal is to create a portfolio that feels like a **real-world professional developer website**, rather than a basic beginner HTML assignment. 🎨💻

Project Live Deployed URL :- https://jj-portfolio-webpage.netlify.app/

---

## ✨ Project Overview

This personal portfolio website is designed to showcase a developer's:

- 👋 Introduction
- 👤 About information
- 🛠️ Technical skills
- 💼 Projects
- 🎓 Education & experience
- ⚙️ Development workflow
- 🎯 Hobbies & interests
- 🏆 Achievements / certifications
- 📬 Contact information
- 🔗 Social profiles

The website includes carefully designed **Light Mode and Dark Mode experiences**, fully responsive layouts, semantic HTML, accessible components, and subtle CSS animations.

# 📱 Responsive Design

The website is designed to work across:

- 🖥️ Large Desktop
- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

### Responsive Breakpoints

```css
@media (max-width: 1024px) @media (max-width: 768px) @media (max-width: 480px);
```

### 📱 Mobile Experience

On smaller screens:

- Navigation becomes a hamburger menu
- Hero becomes single-column
- Project grid becomes single-column
- Contact layout becomes single-column
- Typography scales down
- Images remain responsive
- Buttons remain touch-friendly
- Cards remain readable
- Horizontal overflow is avoided

---

# 🧭 CSS-Only Mobile Navigation

Because JavaScript is not allowed, the mobile menu uses CSS techniques such as:

- Hidden checkbox
- Label-based toggle
- CSS sibling selectors

This allows the navigation to open and close without JavaScript.

# 🧹 CSS Architecture

The stylesheet follows a logical structure:

```text
1. CSS Reset / Base
2. Root Variables
3. Typography
4. Global Layout
5. Header
6. Navigation
7. Hero
8. About
9. Skills
10. Projects
11. Education
12. Process
13. Hobbies
14. Achievements
15. Contact
16. Footer
17. Theme Toggle
18. Animations
19. Responsive Media Queries
20. Reduced Motion
```

CSS custom properties are used to make the theme system easier to maintain.

Example:

```css
:root {
  --bg-primary: #fdf9f3;
  --bg-surface: #ffffff;
  --text-primary: #1f1e1d;
  --text-secondary: #6b6661;
  --accent: #e06d53;
}
```

The dark theme overrides these variables rather than duplicating the entire stylesheet.
